how the differnt messages flow between Client and Provider

                                                                MSG 4031 No contact with Vehicle 1)


               1) Used to indicate that vehicle that service provider no longer have contact with a vehicle.
               2) Client answer a request for traffic information from a vehicle not performing any order for the client for the moment. Signals that the
               provider can release that vehicle if it is marked to be working for the client.
               3) MSG 4040 Request for vehicle. Replaced by MSG 2000 Order with a Processing attribute that indicates that it is a standing order that
               is about to be carried out.
               4) MSG 4041 Reply Request for Vehicle. Replaced by either a MSG 3003 Dispatch Confirmation if the requested vehicle is ready or a
               MSG 2002 Order Reject if the requested vehicle cant carry out the order.
               5) MSG 4012 shall always contain an explanation why message 4010 has been received with complaints.

                                                        MSG 7099 confirmation of received message

               1) Used to signal that a prepared shutdown will start. Purpose is to give the other side time to finish ongoing orders in an
               orderly way., clening up
               2) Used to signal back to the system that will perform a shutdown that the other system has finished the cleaning up and is
               listening for ReStart message that indicates that the system perfoming shutdown is back onlina and operational.
               3) Used to signal emergency shutdown. This message gives no time to clean up and the shutdown will follow shortly after this
               message.
               4) Sent by the system that performed a shutdown. Indicates that the system is back online and are starting cleanup
               procedures.
               5) Sent by the system that performed a shutdown. Indicates that the system is back online and is fully operational.
               6) Used as answer on requests that can not be handled. For example a requst for traffic information after the order the reque st
               referes to has been ended. Telegram can be used from both sides.

COMMON DEMANDS
                                                   Suti
-Secure information about Sender, Reciever
-Timestamp from sending system
-TelegramID used to uniqelly identify every sent
message. Format shall be
YYYYMMDDXXXXXXXXXXXX. YYYY is the
year the message is sent. MM is the month the
message is sent. DD is the date the message is
sent. XXXXXXXXXXXX is a counter that resets
at midnight every day.
-Messages that can not be handled by the
recieving part due to different verions at the
sender and the reciever, shall be answerwered
by sending MSG 4030 NOT OPERATIONAL.
