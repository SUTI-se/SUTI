# Block 90: Alterations (Version History)

> SUTI standard version history and evolution

---

## Overview

**Block 90** documents the evolution of the SUTI standard across versions, tracking alterations, additions, and changes to messages.

---

## Version History

### Version SUTI 2026 (Current)
*Current production version*

### Version SUTI 2019
- Traffic Control: 4040, 4041, 4042 added
- Messages 4100, 4101, 4102 added

### Version SUTI 2017
- Messages 2060, 2061 renamed
- Messages 2014, 4011, 4021 added
- Messages 2540, 2541 added
- Message 3013 added
- Messages 1000-1012 altered and activated
- Messages 1100-1102, 1110-1112 added
- Messages 1061, 6061 added

### Version SUTI 2016
- Messages 2030, 2031, 2032 activated
- Message 8182 added

### Version SUTI 2015
- Block 80 (Accounting) added

### Version SUTI 2014
- Repetetive order messages added

### Version SUTI 2013.1
- Messages 2060, 2061 added

### Version SUTI 2013
- Text altered in MSG 2005, 2006, 2007

### Version SUTI 2012
- Document changed to SUTI 2012

### Version 2.4.0
- Message 6511 added in Block 60

### Version 2.3.0
- Messages 6500, 6501, 6502, 6510 added in Block 60
- Message 6000 changed to MSG 2531 orderStatus (moved to Block 20)
- Messages 2530, 2532, 2900, 2901, 2902 added in Block 20

### Version 2.2.0
- Messages 1020, 1021, 1022, 1023, 1024, 1025 added

### Version 2.0.0
- Message 6001 added in Block 60
- Messages 2020, 2021, 2022, 2023 added in Block 20
- Message 2050 added in Block 20

### Version 1.0.2
- Message 5040 altered to 2040 and introduced in XML schema
- Message 5021 removed from Block 40
- Position replaced with Location
- Message 4010 altered from "Pick-up Confirmation" to "Event Confirmation"

### Version 1.0.0
- Telegram 4030 moved to Block 70 and renamed 7031
